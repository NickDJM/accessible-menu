Hello Accessible Menu!

This is a demo and manual testing application for accessible-menu.

This app allows you to swap between one, two, and three levels of navigation for all supported types of menus provided by accessible-menu. Use the settings below to try optional keyboard support, hover behavior, transitions, and responsive actions.

You can also swap between light and dark mode, which is not part of the library. Just a nice-to-have while playing around with the options.

For more in-depth information about how accessible-menu works, please read the documentation.

Responsive Settings

Set a breakpoint first, then choose the actions to apply on each side of it. These settings apply to the main menu, not its submenus. Select a menu type other than Native DOM to try them.

Include a CSS unit, such as 768px or 48rem. Leave blank to use no width breakpoint.

Optional. A custom query takes priority over the breakpoint.

With a breakpoint, the query matches at or below that width. With a custom query, it matches when that query's conditions are met. Actions run when the menu is created and when the query changes.
